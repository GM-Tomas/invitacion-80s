# 📼 Invitación de Cumpleaños - Temática Años 80

Aplicación interactiva construida con [Next.js](https://nextjs.org) (App Router), TypeScript y Tailwind CSS para una fiesta de cumpleaños temática retro 80s.

## 🚀 Tecnologías

- **Framework:** Next.js 16 (App Router)
- **Estilos:** Tailwind CSS v4
- **Iconos:** Lucide React
- **Efectos:** Canvas Confetti
- **Deploy:** Vercel

## 🛠️ Desarrollo local

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.
