# 🎵 Canción de fondo

Poné acá la canción (mp3, m4a, aac, ogg o wav). **El nombre no importa**: se usa el primer archivo de audio que haya en esta carpeta.

- Arranca cuando el invitado toca **PLAY** en la pantalla de inicio (los celulares no permiten autoplay sin un toque).
- Suena en loop y se puede pausar con el disco flotante abajo a la derecha.
- Si no hay archivo, la invitación funciona igual y el botón de música no aparece.
- Después de agregarla, hacé commit + push para que se redeploye.
